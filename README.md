# Machine Learning Internship Projects
### Bharat Intern — Machine Learning Internship (Sep 2023 – Oct 2023)

This repository contains three end-to-end machine learning projects completed during my ML internship at Bharat Intern. Each project covers the full pipeline: data loading, preprocessing, feature engineering, model training, evaluation, and results analysis.

---

## Projects

### Task 1 — House Price Prediction
**Goal:** Predict residential property prices based on features such as area, number of rooms, location, and amenities.

**Approach:**
- Exploratory Data Analysis (EDA) to understand feature distributions and correlations
- Data cleaning and handling of missing values
- Feature engineering and selection to improve model performance
- Linear Regression model trained and evaluated

**Results:**
- Achieved **90%+ accuracy** on test data
- Improved model efficiency by **15%** through dataset engineering and feature selection

**Tech:** Python, Scikit-learn, Pandas, NumPy, Matplotlib, Jupyter Notebook

---

### Task 2 — Wine Quality Prediction
**Goal:** Predict the quality score of wine (0–10) based on physicochemical properties such as acidity, sugar content, and alcohol level.

**Approach:**
- Applied both Linear Regression and Logistic Regression
- Logistic Regression used for improved classification results
- Feature scaling and correlation analysis
- Model comparison to select the best approach

**Tech:** Python, Scikit-learn, Pandas, NumPy, Seaborn, Jupyter Notebook

---

### Task 3 — Iris Flower Classification
**Goal:** Classify iris flowers into three species (Setosa, Versicolor, Virginica) based on petal and sepal measurements.

**Approach:**
- Classic multi-class classification problem
- Feature visualisation to understand species separability
- Trained and evaluated classification model
- Achieved **90%+ accuracy** on test set

**Tech:** Python, Scikit-learn, Pandas, Matplotlib, Jupyter Notebook

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/Kamineni-Pradeep/Bharat-intern-Ml.git
cd Bharat-intern-Ml
```

2. Install dependencies:
```bash
pip install pandas numpy scikit-learn matplotlib seaborn jupyter
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

4. Open any `.ipynb` file and run all cells.
